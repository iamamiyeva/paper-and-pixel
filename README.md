# 📚 Paper & Pixel (Book Tracking Web Application)

> *"Where timeless literature meets modern software architecture."*

---

## 📖 About the Project

**Paper & Pixel** is a full-stack web application designed to bridge the gap between classical literary passion and modern software development. Born out of a profound appreciation for immortal literature, philosophical works, and contemporary narratives, this platform provides an aesthetic, distraction-free digital sanctuary for readers to explore and manage book collections.

This project marks the evolution of an initial relational database schema into an interactive, full-stack web product.

---

## 🎯 Core Features

- **Dynamic Catalog:** Live fetching and rendering of book details, cover images, summaries, and page counts from the SQL database.
- **Category Filtering:** Filter books dynamically by genre, author, or literary era.
- **RESTful API Backend:** Clean architecture powered by Flask handling request routing, CORS headers, and database interactions.
- **Literature-Inspired UI:** Responsive, warm-toned interface designed with clean HTML5, CSS3, and modern JavaScript[cite: 1].

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask API, Flask-CORS[cite: 1]
- **Database:** MS SQL Server (`LibraryDB`) / SQLite[cite: 1]
- **Frontend:** HTML5, CSS3, JavaScript (ES6+ Fetch API)[cite: 1]
- **Icons & UI:** Material Symbols Outlined[cite: 1]
